Getting started with CADe SIMU And lab sheet 1

CADe SIMU เป็นโปรแกรมฟรีสำหรับเขียนแบบและจำลองวงจรควบคุมไฟฟ้าด้วยสัญลักษณ์แบบ IEC พัฒนาโดยผู้เขียนบล็อก canalPLC จากสเปน วิชานี้ใช้ CADe SIMU เขียนแบบทุกบท เพราะเมื่อวาดเสร็จ กดจำลองแล้วจะรู้ทันทีว่าวงจรทำงานตามที่ตั้งใจหรือไม่ หน้านี้แนะนำหน้าต่างของโปรแกรม การตั้งค่าครั้งแรก และวงจรแรก: แหล่งจ่าย 3 เฟส ฟิวส์ เบรกเกอร์ และมอเตอร์ ใบงานที่ 1 ครูแจกในคาบปฏิบัติ

CADe SIMU is a free program for drawing and simulating electrical control circuits with IEC-style symbols, written by the author of the Spanish canalPLC blog. This course uses it for every drawing, because once a circuit is drawn a press of the simulate button shows at once whether it works as intended. This page tours the program window, the first-time settings and a first circuit: a three-phase supply, fuses, a circuit breaker and a motor. Lab sheet 1 is handed out in class.

ประเด็นสำคัญของหน้านี้

  • ใช้รุ่นเดียวกันทั้งห้อง: ใช้ไฟล์โปรแกรมที่ครูแจก (ผู้พัฒนาส่งลิงก์ดาวน์โหลดให้ทางอีเมลจากบล็อก canalPLC) เว็บดาวน์โหลดอื่นส่วนใหญ่ไม่ใช่ของผู้พัฒนา CADe SIMU ใช้ได้เฉพาะ Windows และไม่ต้องติดตั้ง: แตกไฟล์แล้วเปิดได้เลย
  • อุปกรณ์ผูกกันด้วยชื่อ: คอยล์ชื่อ KM1 สั่งหน้าสัมผัสทุกตัวที่ชื่อ KM1 ชื่ออุปกรณ์จึงห้ามซ้ำกัน เช่น มีเบรกเกอร์ CB แล้ว ตัวที่สองต้องชื่อ CB1
  • จำลองได้แค่เปิด–ปิด: สายที่มีไฟเปลี่ยนสี มอเตอร์แสดงทิศหมุน และโปรแกรมหยุดพร้อมเตือนเมื่อลัดวงจร แต่ไม่คำนวณแรงดันหรือกระแส ตัวเลขเหล่านั้นดูได้จากหน้าเว็บของวิชา
  • บันทึกเป็น .cad โดยพิมพ์นามสกุลเองเมื่อบันทึกครั้งแรก และกรอกกรอบชื่อแบบ (title block) ทุกแผ่น ซึ่งโปรแกรมใช้คำภาษาสเปน

Key points of this page

  • Everyone uses the same version: the copy the instructor hands out (the author sends download links by e-mail from the canalPLC blog); most other download sites are not the author's. CADe SIMU runs on Windows only and needs no installer: unzip and run.
  • Devices are linked by name: a coil named KM1 drives every contact named KM1, so names must not repeat. With one breaker named CB, a second one must be CB1.
  • It simulates on/off only: live wires change colour, the motor shows its direction, and the program stops with a warning on a short circuit, but it calculates no voltages or currents. Those numbers are on the course web pages.
  • Save as .cad, typing the extension yourself the first time, and fill in the title block of every sheet; the program labels it in Spanish.

หน้าต่างของ CADe SIMU

The CADe SIMU window

ภาพหน้าจอจากเอกสารอบรม "การเขียนแบบและต่อตู้คอนโทรล" 2568 ของสาขา
Screenshot from the department's 2025 training notes on drawing and wiring control panels

เมื่อเปิดโปรแกรม จะเห็นแผ่นเขียนแบบที่มีกรอบ ตารางพิกัด A–H กับ 1–5 และกรอบชื่อแบบที่มุมล่าง ส่วนประกอบของหน้าต่าง:

  • แถบเมนู File, Edit, Draw, Mode, View, Bars, Window, Help
  • แถวเครื่องมือแถวแรก: เปิด บันทึก พิมพ์ คัดลอก และปุ่มจำลอง: สามเหลี่ยมสีเขียว = เริ่มจำลอง, สี่เหลี่ยมสีแดง = หยุด, ปุ่มคู่ = หยุดชั่วคราว
  • แถวที่สองและสาม: คลังสัญลักษณ์แยกเป็นกลุ่ม (แหล่งจ่าย อุปกรณ์ป้องกัน มอเตอร์ คอนแทกเตอร์ ปุ่มกด หลอด เซนเซอร์ และสายไฟ) กดปุ่มกลุ่มแล้วเลือกสัญลักษณ์มาวาง
  • แถบซ้าย: เครื่องมือวาดเส้น กรอบ วงกลม และข้อความ แถบขวา: สีและความหนาของเส้น
  • แถบสถานะด้านล่าง: พิกัดของเมาส์ และโหมด "Edición" (กำลังแก้ไข) หรือ "Stop/Simulación"

When the program opens you see a drawing sheet with a border, grid references A–H and 1–5, and a title block in the bottom corner. The parts of the window:

  • Menu bar: File, Edit, Draw, Mode, View, Bars, Window, Help.
  • First toolbar row: open, save, print, copy, and the simulation buttons: green triangle = start, red square = stop, double bar = pause.
  • Second and third rows: the symbol libraries in groups (supplies, protection, motors, contactors, push buttons, lamps, sensors and wires). Press a group and pick a symbol to place.
  • Left bar: tools for lines, rectangles, circles and text. Right bar: line colour and width.
  • Status bar: the mouse position and the mode, "Edición" (editing) or "Stop/Simulación".

First-time settings

คู่มือ CADe SIMU · ทำครั้งเดียวต่อเครื่อง
CADe SIMU manual · once per computer
  1. แตกไฟล์ที่ครูแจกลงโฟลเดอร์ที่เขียนไฟล์ได้ (เช่น เดสก์ท็อป) แล้วเปิดไฟล์ .exe ถ้าโปรแกรมถามรหัส รหัสอยู่ในไฟล์ข้อความในโฟลเดอร์เดียวกัน
  2. ความเร็วจำลอง: เมนู File → Configuration ตั้งความเร็วให้ตัวตั้งเวลานับตรงกับวินาทีจริง (ใช้ในบทที่ 4 เป็นต้นไป) แล้วจับเวลาเทียบ
  3. แสดงเลขสาย: เปิดตัวเลือกแสดงหมายเลขสาย (Visualizar número de cable) ใช้ในบทที่ 5 ตอนเขียนแบบสายไฟ
  4. บันทึกครั้งแรก: พิมพ์ชื่อไฟล์พร้อมนามสกุล .cad เอง เช่น 65xxxx_ใบงาน1.cad
  5. พิมพ์เป็น PDF: เมนู File → Print แล้วเลือกเครื่องพิมพ์ PDF ของ Windows (Microsoft Print to PDF)
  1. Unzip the instructor's file into a folder you can write to (the desktop, say) and open the .exe. If it asks for a key, the key is in a text file in the same folder.
  2. Simulation speed: File → Configuration; set the speed so that timers count real seconds (needed from chapter 4 on), and check it with a stopwatch.
  3. Show wire numbers: turn on the wire-number option (Visualizar número de cable), needed for wiring diagrams in chapter 5.
  4. First save: type the file name with the .cad extension yourself, e.g. 65xxxx_lab1.cad.
  5. Print to PDF: File → Print and pick the Windows PDF printer (Microsoft Print to PDF).

วงจรแรก: แหล่งจ่าย ฟิวส์ เบรกเกอร์ มอเตอร์

A first circuit: supply, fuses, breaker, motor

ใบงานที่ 1 ตอนที่ 3 · ชื่ออุปกรณ์ตามไฟล์ใบงานของรายวิชา
Lab sheet 1, part 3 · device names as in the course's lab files

ไฟล์ใบงานแผ่นที่ 2 ที่ครูแจกวางอุปกรณ์ไว้ให้แล้ว: เส้นเมน -X (L1 L2 L3 N PE) ฟิวส์ 3 ขั้ว F เบรกเกอร์ 3 ขั้ว CB และมอเตอร์ -M โดยแต่ละอุปกรณ์มีทั้งสัญลักษณ์ (ซ้าย) และภาพเสมือนจริง (ขวา) งานของนักศึกษาคือ ต่อสาย:

  1. ลากสายจากเส้นเมน L1 L2 L3 ลงไปที่ขั้ว 1, 3, 5 ของฟิวส์ F
  2. ต่อขั้ว 2, 4, 6 ของฟิวส์ไปขั้ว 1, 3, 5 ของเบรกเกอร์ CB
  3. ต่อขั้ว 2, 4, 6 ของเบรกเกอร์ไปขั้ว U1, V1, W1 ของมอเตอร์ และต่อ PE เข้าขั้ว PE
  4. กดเริ่มจำลอง แล้วคลิกเบรกเกอร์ให้สับ (ON) ดูสายที่มีไฟเปลี่ยนสีและมอเตอร์หมุน
  5. หยุดจำลอง สลับสาย L1 กับ L2 ที่ขั้วมอเตอร์ แล้วจำลองใหม่: มอเตอร์ต้องหมุนกลับทาง (หน้า 1.1)

แบบที่อยู่ถัดจากภาพใบงานคือคำตอบที่เขียนตามสัญลักษณ์ IEC: ลำดับจากบนลงล่าง เส้นเมน → ฟิวส์ → เบรกเกอร์ → มอเตอร์ เลขขั้วเขียนกำกับทุกจุด และสายดินเป็นเส้นประสีเขียว

Sheet 2 of the instructor's lab file has the devices already placed: supply rails -X (L1 L2 L3 N PE), a three-pole fuse F, a three-pole breaker CB and a motor -M, each as a symbol (left) and as a picture (right). The student's job is the wiring:

  1. Draw wires from rails L1 L2 L3 down to terminals 1, 3, 5 of fuse F.
  2. Wire fuse terminals 2, 4, 6 to breaker terminals 1, 3, 5.
  3. Wire breaker terminals 2, 4, 6 to motor terminals U1, V1, W1, and PE to the motor's PE terminal.
  4. Start the simulation and click the breaker on; watch the live wires change colour and the motor turn.
  5. Stop, swap L1 and L2 at the motor terminals and simulate again: the motor must reverse (page 1.1).

The drawing next to the lab-file picture is the answer in IEC symbols: from top to bottom, rails → fuses → breaker → motor, every terminal numbered, and the earth as a green dashed line.

ใบงานที่ 1

Lab sheet 1

เวลา 2 ชั่วโมง · 100 คะแนน
2 hours · 100 points

การอ่านป้ายพิกัด การต่อขั้วมอเตอร์ และการเขียนวงจรกำลังมอเตอร์ด้วย CADe SIMU มี 4 ตอน: (1) อ่านป้ายพิกัดมอเตอร์ในห้องปฏิบัติการและมอเตอร์ 7.5 kW (2) เขียนการต่อสะพานในกล่องขั้ว 4 แบบ (3) ต่อสายและจำลองวงจรกำลังใน CADe SIMU ทั้ง 3 เฟสและ 1 เฟส พร้อมกรอกกรอบชื่อแบบ (4) คำถามท้ายใบงาน ทบทวนหน้า 1.1–1.3 ก่อนทำ

Reading nameplates, connecting motor terminals and drawing motor power circuits in CADe SIMU, in four parts: (1) read the nameplates of the lab motor and of a 7.5 kW motor; (2) draw the links in the terminal box for four cases; (3) wire and simulate the three-phase and single-phase power circuits in CADe SIMU and fill in the title block; (4) questions. Review pages 1.1–1.3 first.

ใบงานที่ 1 ครูแจกเป็นกระดาษในคาบปฏิบัติ ไม่มีให้ดาวน์โหลด เตรียมตัวโดยอ่านหน้า 1.1–1.3 และลองภาพจำลองทุกหน้าให้ครบก่อนมาเรียน

Lab sheet 1 is handed out on paper in the practical session; it is not available for download. Prepare by reading pages 1.1–1.3 and trying every simulation before class.
