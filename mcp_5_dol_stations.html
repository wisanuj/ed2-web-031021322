Terminal strips, two stations, jogging and fault finding The DOL starter continued, then the first faults to find with the meter

สัปดาห์นี้ต่อยอดวงจรเริ่มเดินโดยตรง (direct-on-line, DOL) ของสัปดาห์ที่แล้ว: อ่านตารางแผงขั้วต่อ -X1 และ -X2 ว่าสายไหนออกจากแผ่นยึดอุปกรณ์ไปที่ประตูตู้และมอเตอร์ ต่อวงจรสองจุดควบคุม วงจรเดินกระตุกแบบรีเลย์ช่วย และรีเลย์ป้องกันเฟส F3 ตามใบงานของครูแผ่นที่ 10–11 บนแผงฝึก แล้วจ่ายไฟทดสอบตามตาราง ครึ่งหลังของสัปดาห์เป็นการหาจุดผิดครั้งแรก: ครูทำจุดเสียไว้ในวงจรครบชุดโดยดูจากภายนอกไม่ออก ให้ดูอาการแล้วใช้มิเตอร์หาจุดเสียให้ได้ในจำนวนครั้งที่กำหนด หลักการของวงจรอยู่ในหน้า 5.3–5.6 ของวิชาเขียนแบบไฟฟ้า 2

This week builds on last week's direct-on-line (DOL) starter. Read the -X1 and -X2 terminal tables to see which wires leave the mounting plate for the door and the motor, then wire two control stations, a relay jog circuit and phase-failure relay F3 (the instructor's sheets 10–11) on the trainer and test each with power. The second half of the week is your first fault finding: the teacher has set hidden faults in the complete circuit; read the symptom, then find the fault with the meter in a limited number of measurements. How the circuits work is on pages 5.3–5.6 of Electrical Drawing II.

ประเด็นสำคัญของหน้านี้

  • แผงขั้วต่อ: สายทุกเส้นที่ออกจากแผ่นยึดอุปกรณ์ไปประตูตู้ สถานีควบคุมที่ 2 หรือมอเตอร์ ต้องลงขั้วของแผงขั้วต่อ -X1 คือสายกำลังและมอเตอร์ -X2 คือสายควบคุม สายเลขเดียวกันใช้ขั้วเดียวกัน สายดินป้องกัน (protective earth, PE) และ N มีขั้วของตัวเอง
  • สองจุดควบคุม: ปุ่มหยุดทุกตัวต่ออนุกรม ปุ่มเริ่มทุกตัวต่อขนานกับหน้าสัมผัสค้างตัวเอง (หน้า 3.3 และ 5.6) ปุ่มหยุดตัวใดก็หยุดมอเตอร์ได้ ปุ่มเริ่มตัวใดก็เริ่มได้
  • เดินกระตุกแบบรีเลย์ช่วย: ปุ่มเริ่ม S2 สั่งรีเลย์ KA1 ซึ่งค้างตัวเองแล้วสั่ง KM1 ส่วนปุ่มเดินกระตุก S3 ป้อนคอยล์ KM1 ตรงและไม่ไปถึงทางค้างตัวเองเลย บนแผงฝึก KA1 เป็นรีเลย์แบบเสียบ ขั้ว 13–14 ในแบบจึงเป็น 11–14 บนตัวรีเลย์
  • หาจุดผิดด้วยการวัด: ดูอาการ หาทางเดินกระแสที่เกี่ยวข้อง แล้ววัดแรงดันโดยวางสายวัดดำไว้ที่ N และเลื่อนสายวัดแดงไปตามทางเดินกระแส จุดที่แรงดันหายไปอยู่ระหว่างจุดที่วัดได้ 230 V กับจุดที่วัดได้ 0 V (หน้า 5.5)

Key points of this page

  • Terminal strips: every wire that leaves the mounting plate for the door, the second station or the motor lands on a strip terminal: -X1 for the power and motor wires, -X2 for the control wires. One wire number uses one terminal; the protective earth (PE) and N have terminals of their own.
  • Two stations: all stop buttons in series, all start buttons in parallel with the holding contact (pages 3.3 and 5.6). Any stop button stops the motor and any start button starts it.
  • Relay jogging: start button S2 drives relay KA1, which holds itself and drives KM1; jog button S3 feeds coil KM1 directly and never reaches a holding path. On the trainer KA1 is a plug-in relay, so 13–14 in the drawing is 11–14 on the relay.
  • Fault finding by measuring: read the symptom, find the current path involved, then measure voltage with the black probe left on N while the red probe moves along the path. The fault lies between the last point that reads 230 V and the first that reads 0 V (page 5.5).

    Fault cards: find it in as few measurements as you can

    หน้า 5.5 · วงจรครบชุดของสัปดาห์ที่ 4
    Page 5.5 · the complete circuit of week 4

    การ์ดแต่ละใบมีจุดเสียหนึ่งจุดที่ครูทำไว้ แบบวงจรยังดูถูกต้องทุกอย่างและไม่แสดงสีของสายที่มีไฟ เหมือนแผงฝึกจริงที่มองไม่เห็นว่าสายไหนมีไฟ ขั้นตอนเหมือนหน้า 5.5: (1) ใช้งานวงจรดูอาการ ปุ่ม "กด S2 ค้าง" ช่วยกดปุ่มให้ขณะที่มือทั้งสองถือสายวัด (2) หาทางเดินกระแสที่เกี่ยวข้องในแบบ (3) วัดแรงดันโดยวางสายวัดดำที่ N แล้วแตะสายวัดแดงไล่ไปตามทาง ถ้าเลือกจุดกึ่งกลางของทางก่อน จะตัดทางทิ้งได้ครึ่งหนึ่งทุกครั้งที่วัด (4) เมื่อแน่ใจแล้วกด "เจอแล้ว" แล้วแตะขั้ว อุปกรณ์ หรือสายที่เสียในแบบ

    คะแนน: 3 = เจอภายในจำนวนครั้งที่กำหนดโดยไม่ตอบผิด 2 = เกินมาไม่เกินสองครั้งและตอบผิดไม่เกินหนึ่งครั้ง 1 = เจอแต่ใช้การวัดมากกว่านั้น 0 = เปิดดูเฉลย ปุ่มแหล่งจ่ายของมิเตอร์ใช้ตัดไฟเมื่อจะวัดโอห์ม ค่าที่มีโหลดเป็นค่าตัวอย่าง

    Each card hides one fault set by the teacher. The drawing still looks correct and shows no live colours, just as on the real trainer you cannot see which wire is live. The routine is that of page 5.5: (1) operate the circuit and read the symptom; the "hold S2" button keeps a button pressed while both your hands hold the probes. (2) Find the current path involved in the drawing. (3) Measure voltage with the black probe on N, touching the red probe along the path; start in the middle of the path and every measurement rules out half of it. (4) When you are sure, press "Found it" and tap the faulty terminal, device or wire in the drawing.

    Points: 3 = found within the allowed number of measurements with no wrong answer; 2 = up to two more measurements and at most one wrong answer; 1 = found with more measurements than that; 0 = answer shown. The meter's supply button isolates the circuit when you want to measure ohms; readings through loads are example values.

    ใบงานครูแจกเป็นกระดาษในห้องปฏิบัติ หน้านี้ไม่มีไฟล์ให้ดาวน์โหลด ในใบงานมีตารางแผงขั้วต่อให้กรอก แบบวงจรของงานที่ครูกำหนดให้เขียนเลขสาย ตารางทดสอบก่อนและหลังจ่ายไฟ ช่องให้ครูลงชื่อก่อนจ่ายไฟ และงานหาจุดผิดที่ครูทำไว้บนแผงฝึกจริง: เขียนอาการ จุดที่วัดพร้อมค่าที่อ่านได้ตามลำดับ จุดเสียที่พบ และวิธีแก้
    The practice sheet is handed out on paper in the lab; there is no file to download on this page. It has a terminal table to fill in, the drawing of the job the teacher sets for you to number, the before-power and after-power test tables, a box for the teacher's signature before power-on, and a fault-finding task the teacher sets on the real trainer: write the symptom, each point you measured with its reading in order, the fault you found and the repair.

    Terminal strips, two stations, jogging and fault finding

    ลองทำดู

    1. หัวข้อ C: ต่อวงจรสองจุดควบคุมให้ผ่าน แล้วเปลี่ยนเป็นวงจรรีเลย์ป้องกันเฟสโดยเก็บสายเดิมไว้ ดูว่าต้องเพิ่มสายเส้นไหนบ้าง
    2. หัวข้อ D วงจรเดินกระตุก: กด S3 ขณะมอเตอร์เดินต่อเนื่องแล้วปล่อย มอเตอร์หยุดหรือไม่ เพราะอะไร
    3. หัวข้อ E: ทำการ์ดทุกใบให้ได้ 3 คะแนน แล้วเขียนลำดับจุดที่วัดของการ์ดที่ยากที่สุดลงในใบงาน

    Try this

    1. Section C: get the two-station circuit to pass, then change to the phase-failure circuit keeping your leads, and see which leads you have to add.
    2. Section D, jog circuit: press and release S3 while the motor runs continuously. Does the motor stop? Why?
    3. Section E: get 3 points on every card, then write the sequence of points you measured on the hardest card on your practice sheet.
