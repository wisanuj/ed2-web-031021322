Jogging circuit The motor runs only while the button is pressed

วงจรควบคุมมอเตอร์ที่ง่ายที่สุดคือวงจรเดินกระตุก (jogging): กดปุ่ม S1 ค้างไว้ คอยล์ของคอนแทกเตอร์ K1 มีไฟ หน้าสัมผัสหลักต่อ มอเตอร์เดิน ปล่อยปุ่ม สปริงดันหน้าสัมผัสกลับ มอเตอร์หยุด ใช้ขยับเครื่องจักรทีละนิด เช่น เลื่อนสายพานหรือตะขอเครนให้ตรงตำแหน่ง หน้านี้ใช้ชื่ออุปกรณ์ตามสไลด์บทที่ 2: F1 ฟิวส์วงจรกำลัง F2 ฟิวส์วงจรควบคุม S0 ปุ่มหยุดฉุกเฉิน S1 ปุ่มเดินกระตุก K1 คอนแทกเตอร์ H1 หลอดสัญญาณ M1 มอเตอร์

The simplest motor control circuit is the jogging circuit: hold push button S1 and the coil of contactor K1 is energised, its main contacts close and the motor runs; let go and the spring opens the contacts, and the motor stops. It is used to move a machine a little at a time, for example to bring a conveyor or a crane hook to the right place. This page uses the names of the Lecture 2 slides: F1 power fuses, F2 control fuse, S0 emergency stop, S1 jog button, K1 contactor, H1 pilot lamp, M1 motor.

ประเด็นสำคัญของหน้านี้

  • เดินกระตุก = เดินเฉพาะตอนกด: ปุ่ม S1 เป็นปุ่มกดแบบเด้งกลับ ไม่มีหน้าสัมผัสค้างวงจร ปล่อยปุ่มเมื่อไร มอเตอร์หยุดทันที
  • สองวงจร: วงจรกำลัง L1 L2 L3 → F1 → หน้าสัมผัสหลัก K1 → M1 และวงจรควบคุม F2 → S0 → S1 → คอยล์ K1 → N
  • 4 กลุ่มอุปกรณ์: ระบบไฟ (L1 L2 L3 N PE) อุปกรณ์ป้องกัน (F1 F2) อุปกรณ์ควบคุม (S0 S1) และโหลด (คอยล์ K1 หลอด H1 มอเตอร์ M1)
  • S0 หยุดฉุกเฉิน: ปุ่มหัวเห็ดสีแดง เป็นหน้าสัมผัส NC กดแล้วล็อกค้าง ต้องบิดคืนก่อน มอเตอร์จึงเดินได้อีก

Key points of this page

  • Jogging = running only while pressed: S1 is a spring-return push button and there is no holding contact. The moment you let go, the motor stops.
  • Two circuits: the power circuit L1 L2 L3 → F1 → main contacts K1 → M1, and the control circuit F2 → S0 → S1 → coil K1 → N.
  • Four groups of devices: the supply (L1 L2 L3 N PE), protection (F1, F2), control devices (S0, S1) and loads (coil K1, lamp H1, motor M1).
  • S0 emergency stop: a red mushroom button with an NC contact. It latches when pressed and must be twisted back before the motor can run again.

ใช้ที่ไหน และต่างจากวงจรเริ่มเดินอย่างไร

Where it is used, and how it differs from a starter

การใช้งาน
Uses
  • ขยับทีละนิด: เลื่อนสายพานให้ชิ้นงานตรงตำแหน่ง ขยับตะขอเครน หมุนแกนเครื่องจักรตอนตั้งเครื่อง
  • ปลอดภัยเพราะต้องกดค้าง: ถ้าผู้ใช้ปล่อยมือหรือล้ม มอเตอร์หยุดเอง
  • ใช้เดินยาว ๆ ไม่ได้: ถ้าต้องการให้มอเตอร์เดินต่อหลังปล่อยปุ่ม ต้องเพิ่มหน้าสัมผัสค้างวงจร K1 13–14 คร่อมปุ่มเริ่ม ซึ่งเป็นวงจรเริ่มเดินโดยตรงในสไลด์บทที่ 3 (บนเว็บนี้ดูหน้า 5.1) ส่วนวงจรที่มีทั้งเดินค้างและเดินกระตุกอยู่ในหน้า 5.3
  • Moving a little at a time: bring a workpiece on a conveyor into position, move a crane hook, turn a machine shaft while setting it up.
  • Safe because you must hold it: if the operator lets go or falls, the motor stops by itself.
  • Not for long runs: to keep the motor running after the button is released, a holding contact K1 13–14 is added across the start button: the direct-on-line starter of Lecture 3 (on this site, page 5.1). Circuits with both run and jog are on page 5.3.
